## ✨ Features

- **🧠 Interactive Neural Network Canvas** — Mouse-reactive particle system in the hero section. 75 particles, cyan + violet glowing edges, 60fps vanilla JS canvas
- **⌨️ Typewriter Role Animation** — Cycles through Full Stack Engineer → AI/ML Engineer → Computer Vision Builder → SE Student
- **🎨 Deep-Space Dark Theme** — `#050A0F` background, electric cyan (`#00F5FF`) + violet (`#7B2FFF`) accent system, Space Grotesk + JetBrains Mono typography
- **📦 Projects Showcase** — Detailed cards for each real project with tech stack pills, per-project accent colors, and GitHub links
- **🔧 Tech Stack Grid** — Devicons CDN-powered icon grid across 5 categories: Frontend & Mobile, Backend, AI/ML, Data, DevOps & Tools
- **📍 Vertical Timeline** — Experience section with animated spring nodes and gradient connector lines
- **📱 Fully Responsive** — Mobile → Tablet → Desktop. JS-based responsive navbar (hamburger on mobile, full nav on desktop)
- **🖱 Custom Cursor** — Glowing cyan dot + lagging trail ring, violet on interactive hover
- **🔍 SEO Ready** — Proper meta tags, Open Graph, Twitter card, font preloads

## 🏗 Local Setup

```bash
# 1. Clone the repo
git clone https://github.com/Sudesh-2002/personal-portfolio.git
cd personal-portfolio

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

> **Node.js 18+** required. No environment variables needed — this is a pure frontend project.
